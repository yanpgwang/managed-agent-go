---
title: "Quickstart"
description: "Run Mango locally and complete the first agent session"
---

This walkthrough runs one complete Environment → Agent → Session → Event flow.
It uses the offline model, so no API key is required.

## Requirements

- Docker with Compose
- `curl`
- `jq`

<Steps>
  <Step title="Start Mango">

    ```bash
    make local-up
    make local-health
    curl http://localhost:8080/readyz
    ```

    The stack includes PostgreSQL, Temporal, NATS, MinIO, the API, and a worker.
    The API listens on `http://localhost:8080`; Temporal UI is available at
    `http://localhost:8233`.

  </Step>
  <Step title="Create an environment and agent">

    ```bash
    ENV_ID=$(
      curl -sS http://localhost:8080/v1/environments \
        -H 'content-type: application/json' \
        -d '{"name":"local","config":{"type":"cloud"}}' |
      jq -r .id
    )

    AGENT_ID=$(
      curl -sS http://localhost:8080/v1/agents \
        -H 'content-type: application/json' \
        -d '{"name":"Example agent","model":"offline-fake","system":"Be concise."}' |
      jq -r .id
    )
    ```

    Updating an Agent creates a version. Each Session keeps the Agent version
    and configuration it resolved at creation time.

  </Step>
  <Step title="Create a session">

    ```bash
    SESSION_ID=$(
      curl -sS http://localhost:8080/v1/sessions \
        -H 'content-type: application/json' \
        -d "{\"agent\":\"$AGENT_ID\",\"environment_id\":\"$ENV_ID\",\"title\":\"First session\"}" |
      jq -r .id
    )
    ```

  </Step>
  <Step title="Send a message">

    ```bash
    curl -sS "http://localhost:8080/v1/sessions/$SESSION_ID/events" \
      -H 'content-type: application/json' \
      -d '{
        "events": [{
          "type": "user.message",
          "content": [{"type":"text","text":"hello"}]
        }]
      }' | jq
    ```

    The response acknowledges accepted input. Agent execution is asynchronous,
    so read the event history to get the result:

    ```bash
    curl -sS \
      "http://localhost:8080/v1/sessions/$SESSION_ID/events?order=asc" |
      jq
    ```

    A finished turn includes an `agent.message` followed by
    `session.status_idle`.

  </Step>
</Steps>

## Stream the next turn

Open an SSE connection before sending another message:

```bash
curl -N \
  "http://localhost:8080/v1/sessions/$SESSION_ID/events/stream?event_deltas%5B%5D=agent.message"
```

Preview frames are ephemeral. The final persisted `agent.message` is the source
of truth.

## Clean up

```bash
make local-down
```

This keeps the PostgreSQL and MinIO volumes. Use
`make local-down VOLUMES=1` only when you also want to remove local data.
